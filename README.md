# 🌆 Visit Dubai Website

## 📝 Overview  
The **Visit Dubai** website is a front-end project designed to promote Dubai as a top travel destination. It highlights the city’s attractions, activities, and cultural heritage through a clean and user-friendly interface.  
Built using **HTML**, **CSS**, and a little **JavaScript**, the website combines structure, style, and interactivity to create an engaging browsing experience.

---

## 🗂️ Pages  
- **Home** – Introduces visitors to Dubai with a welcoming overview.  
- **Tourist Attractions** – Highlights popular landmarks and destinations.  
- **Fun Activities** – Showcases leisure and adventure options available in the city.  
- **History** – Explores Dubai’s origins, growth, and cultural background.  
- **Feedback** – Includes a form for users to share their thoughts and experiences.  

---

## ✨ Features  
- Fully responsive design for mobile and desktop devices.  
- Smooth navigation across all pages.  
- Basic animations and interactivity using JavaScript.  
- Visually appealing layout focused on clarity and user experience.  

---

## 🛠️ Technologies Used  
- **HTML5** – Page structure and content  
- **CSS3** – Styling, layout, and responsiveness  
- **JavaScript** – Interactive functionality  

---

## 🎯 Purpose  
This project was created to develop and demonstrate my front-end web development skills. It showcases my ability to design and build a multi-page, responsive website with consistent design principles and engaging content.
